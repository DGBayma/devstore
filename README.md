# DevStore

Loja virtual para desenvolvedores, com os principais assuntos do momento no mundo dev.

## Tecnologias
- Frontend: React + Vite
- Backend: Node.js + Express
- Banco: SQLite (better-sqlite3)

## Como rodar

### Backend
    cd backend
    npm install
    npm run dev

### Frontend
    cd frontend
    npm install
    npm run dev

Backend: http://localhost:3000
Frontend: http://localhost:5173
